# Guitar class: 16 skills

Made with the method that won test 2 (`../ab-test-2/RESULTS.md`): three
fresh Claude sessions working through plain files.

1. **Research** (`RESEARCH.md`):
   - guitar techniques, gear, theory and rock culture;
   - ARPG melee/ranged/caster design;
   - for each skill slot, a real paper and a real game skill.
2. **Associations** (`ASSOCIATIONS.md`): 431 links between papers, game
   mechanics, guitar ideas, toy-world objects and the skill slots.
3. **Design** (`SKILLS.md`): reads both files and fuses each slot's paper,
   game skill and guitar idea into one POE2-style skill.

The field and genre for each slot were drawn at random by a script
(`INSPIRATION.md`). The roles were fixed: 4 melee, 4 ranged, 4 caster, and
4 utility (movement, defence, utility, ultimate).

Cost: $0.94 research + $0.66 associations + $1.08 design = $2.68.

This kit was not A/B tested or reviewed. Citations and game mechanics
marked (!) are uncertain or from memory.
